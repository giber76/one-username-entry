One word, one username, one reward — a program that writes its entrant's own make.fun username, `giber-way`, and nothing else, to `entry.txt` for the judge. One word, no explanation, no links, no pitch: 9 characters, a single word with no spaces and no padding. The program reads the file back and refuses to finish unless what it wrote is exactly the username.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
